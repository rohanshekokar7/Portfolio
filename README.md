Personal Portfolio Website:-
This is the repository for my personal portfolio website, designed to showcase my skills, projects, and professional background as an aspiring web developer. The site is fully responsive, interactive, and includes a variety of modern web technologies to create an engaging user experience.

Live Demo:- https://rohanshekokar.netlify.app/

✨ Features:-
This portfolio is built with a focus on modern design and interactivity. Key features include:

Sleek Preloader: A loading animation ensures a smooth initial experience while assets load.

Interactive 3D Background: A dynamic, animated starfield created with three.js that subtly reacts to cursor movement.

Dark/Light Mode: A theme toggle that saves the user's preference in their browser.

Responsive Design: The layout is fully optimized for all devices, from mobile phones to desktop screens.

On-Scroll Animations: Elements animate into view as you scroll down the page, powered by the AOS library.

Typing Effect: An engaging animated typing effect on the hero section created with Typed.js.

Custom Cursor: A unique cursor for a personalized touch.

Accessibility: ARIA labels and best practices are implemented for improved usability for all users.

3D Project Cards: Project cards have a subtle 3D tilt effect on hover.


🛠️ Technologies Used:-
The project is built using a combination of core web technologies and modern libraries:

Frontend:

HTML5

CSS3

JavaScript (ES6+)

Frameworks & Libraries:

Tailwind CSS: For utility-first styling and responsive design.

Three.js: For the 3D animated background.

AOS (Animate On Scroll): For scroll animations.

Typed.js: For the hero section typing animation.

Font Awesome: For icons.

Google Fonts: For the "Poppins" typeface.


🚀 Setup and Installation
No complex setup is required to run this project locally. Since all libraries are linked via CDN, you just need a modern web browser.


Open the index.html file:
Simply open the index.html file in your favorite web browser (like Chrome, Firefox, or Edge).

File Structure:-

The project is organized into three main files:

index.html: The main HTML structure of the portfolio.

style.css: Contains all the custom CSS for styling, animations, and effects.

script.js: Holds all the JavaScript for interactivity, the 3D background, and other dynamic features.
